Simple terminal-based python gambling game.
Running game:
Step1:
  Download .exe and run! Enjoy
Method2:
  Download.py file and run in python. Enjoy

Gamemodes:
  50/50: There is a 50% chance your bet is doubled
  20/80: There is a 20% chance your bet is multiplied X5
  10/90: There is a 10% chance your bet is multiplied X10
